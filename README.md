# chasefinch/homebrew-tap

Homebrew formulae for [Chase](https://github.com/chasefinch)'s tools.

```bash
brew tap chasefinch/tap
```

## bear-formatter

A formatter for [Bear](https://bear.app) notes.

```bash
brew install chasefinch/tap/bear-formatter
```

## runner

Runs [Runner](https://rnnr.app)'s threads on this Mac, as a service of your own.

```bash
brew install chasefinch/tap/runner
brew services start runner
```
